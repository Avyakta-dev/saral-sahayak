Restricted page: Capture blocked on chrome://, Web Store, PDF viewer, or other uninspectable roots. Recapture unavailable — use manual assistance.

Unsupported target: Cross-origin frame / canvas / opaque overlay inside crop. Coverage cannot be proven → crop denied. No “probably safe” gaps.

Blocked Fill: Page looks like payment/security/claim submit workflow, or field changed since restore. Preflight abort — local/manual result only.

Expired / stale: Vault TTL or page generation mismatch. All approvals cleared. Fresh Inspect + Capture required. Old tokens cannot be reused.
