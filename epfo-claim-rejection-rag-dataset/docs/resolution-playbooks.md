# Resolution playbooks

Practical sequences after a rejection. Always start from the **exact Track Claim remark**.

## 0. Universal first 10 minutes
1. Screenshot claim ID, date, status, full remark.
2. Member portal: Personal Details, Service History (every member ID), Manage > KYC (Aadhaar/PAN/Bank statuses).
3. Confirm UAN login mobile vs Aadhaar mobile.
4. Do **not** file another claim the same day.

## A. Identity / KYC mismatch (001–014)
1. Align **UAN → Aadhaar** (not Aadhaar → payroll nickname) unless Aadhaar is legally wrong.
2. Seed Aadhaar with exact name; complete UIDAI OTP.
3. If match fails, Joint Declaration (minor vs major per SOP). Employer e-signs. Closed shop: physical JD with listed attestors.
4. PAN for Form 19 if service <5 years.
5. Wait for **Verified**, then one refile.

## B. Bank / payment (015–023)
1. Copy account number and IFSC from latest cheque, not Google.
2. Sole savings account in member name (pension: single or joint-with-spouse).
3. Get Bank KYC **Verified** (NPCI). Upload cheque image only if prompted.
4. After merger, update IFSC before claiming.
5. If status is **Settled** but no credit: capture UTR, unfreeze account, EPFiGMS for **re-payment**, do not duplicate the claim.

## C. Employer / DOE / DSC (024–032)
1. Service History must show DOE before Form 19/10C.
2. HR marks exit; else JD / Mark Exit with relieving letter.
3. If KYC Pending, HR must approve with live DSC; expired DSC is an employer fix.
4. Closed establishment: alternative attestation list (gazetted officer, bank manager of claimant account, MP/MLA, etc.).
5. Physical Non-Aadhaar CCF still needs stamp.

## D. Eligibility / wrong form (033–046)
1. Employed + need money → Form 31 purpose the portal enables.
2. Unemployed after waiting period → Form 19; not if a new covered job has started (then Form 13).
3. EPS months <6 → no 10C cash. 6 months–<9.5 years → 10C. ≥10 years → 10D/scheme certificate, not 10C cash.
4. Overlap: correct false dates; for **transfers**, quote circular 20 May 2025 if rejected solely for overlap.
5. Multiple UANs: merge/transfer first.
6. Inoperative: unblock after KYC, then claim.

## D2. Form 31 purpose-specific (082–096, 121, 125, 129, 131)
1. Read the **exact purpose** on Track Claim / your submission — housing ≠ marriage ≠ illness ≠ unemployment.
2. Check membership months and amount caps for **that** purpose (and 25% retention if shown).
3. Post-exit ECR remarks → employer clarification (097/098) before refiling unemployment.
4. COVID vs calamity: different purposes (088/089); do not substitute.
5. Physical illness advances: Certificate C quality (129) separate from eligibility (087).

## E. Death / EDLI / pension family (060–067, 081)
1. Check e-nomination is **e-signed**. If not, follow family/legal-heir path.
2. Death certificate name vs UAN; death-case JD if needed (nominee consent).
3. File the Which-Claim-Form package (20, 10D/10C, 5IF if in service).
4. EDLI: stop if death was after exit unless DOE is wrong or a job-to-job weekend gap applies.
5. Minors: natural guardian or court guardianship.
6. Form 10D: spouse in family details; bank single or with spouse; photos/descriptive roll for offline.

## F. Transfer (068–073)
1. Start Form 13 in month 1 of the new job.
2. Choose an employer who can actually e-sign (often present employer).
3. Align names on source and destination IDs first.
4. Deliver signed printout within 15 days if that flow still applies.
5. Chase **source RO** via EPFiGMS; attach overlap circular if that is the only reason.

## G. International workers (074–075)
1. Do not hammer Aadhaar OTP if you left India without Aadhaar.
2. UAN + physical forms + passport + bank verification; employer confirm if > Rs 5 lakh. Quote 29.11.2024 circular.
3. CoC is a separate IW-portal process with employer e-sign.

## H. Vague remark / parked file (079, 058, 059)
1. Ask employer login.
2. EPFiGMS: UAN, claim ID, paste remark, ask for the specific defect and scheme provision.
3. Escalate inside EPFiGMS, then CPGRAMS. RTI for file noting if still opaque.
4. When the real reason appears, jump to the matching playbook.

## I. Prevention checklist before any online claim
- [ ] UAN activated, Aadhaar mobile works
- [ ] Name/DOB/gender/parent match Aadhaar
- [ ] Aadhaar, PAN, Bank all **Verified**
- [ ] Sole bank account, current IFSC, printed-name cheque if needed
- [ ] Service History: DOJ present; DOE present for 19/10C; no unexplained overlap or unknown member ID
- [ ] Correct form for life event
- [ ] e-nomination e-signed
- [ ] No other claim in process
- [ ] Passbook contributions look complete

## J. What rejection does **not** do
It does not confiscate the PF balance. Interest treatment depends on operative vs inoperative rules. Refile after the defect is gone.
